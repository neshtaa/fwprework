# Intake & Forensics

## Результати аналізу файлу
Поточний файл `fwp(1).exe` є **Standalone Adobe Flash Projector** (виконуваний файл Windows PE32, у який вбудовано рантайм Flash Player та сам SWF).

- **Загальний розмір файлу:** `31,819,826` байт.
- **Розмір Projector Stub (виконуваного коду):** `9,350,816` байт.
- **Offset початку SWF файлу:** `9,350,816` (відразу після stub).
- **Сигнатура SWF:** `FWS` (некомпресований), версія 14 (`0x0E`).
- **Розмір вбудованого SWF файлу:** `22,469,002` байт.
- **Підтвердження:** В кінці файлу розташовано стандартний футер Flash Projector'а (останні 8 байт: сигнатура `56 34 12 FA` та розмір виконуваного stub'а `8A D9 56 01` у форматі little-endian).

## Наступні кроки
1. Написати скрипт для витягування `.swf` файлу (виділити байти від `9350816` до `9350816 + 22469002`).
2. Використати декомпілятори (наприклад, JPEXS Free Flash Decompiler / FFDec) для аналізу вмісту витягнутого `.swf` (ActionScript, спрайти, звуки, ассети).
3. Розпочати реверс-інжиніринг ігрової логіки для подальшого порту на сучасний клієнт-серверний стек.
