# Процес витягування та декомпіляції (Extraction Process)

Цей документ фіксує кроки з витягування SWF файлу з оригінального Standalone Adobe Flash Projector.

## Як саме витягнули SWF

За допомогою попереднього аналізу файлу (`docs/intake_forensics.md`) було виявлено, що виконуваний файл складається з Projector stub та доданого в кінець SWF-файлу. 
В кінці файлу розташовано стандартний футер (8 байт), що містить розмір вбудованого SWF (4 байти, little-endian) та магічну сигнатуру `56 34 12 FA`.

Для автоматизації процесу було написано скрипт на Python (`scripts/extract_swf.py`), який:
1. Зчитує оригінальний файл.
2. Аналізує останні 8 байт (footer).
3. Використовує розмір SWF (чи offset) для визначення точного місця початку SWF-файлу.
4. Перевіряє перші три байти на наявність SWF-сигнатури (у нашому випадку `FWS`).
5. Зберігає відсічений вміст у файл `extracted/game.swf`.

### Використані команди та скрипти
- Скрипт екстракції: `python3 scripts/extract_swf.py`
- Перевірка розміру і хешів: утиліти `stat` та `sha256sum`.

## Отримані артефакти

1. **`extracted/game.swf`**
   - **Оригінальний файл (`fwp(1).exe`) не зазнав жодних змін.** (Розмір: 31,819,826 байт, SHA256: `d4e3afea55f52ef6b4d7eea83e73ccc2269914edf0ddb634b4088196ae3282ea`)
   - **Сигнатура:** `FWS` (некомпресований SWF).
   - **Версія SWF:** `14`.
   - **Фактичний розмір SWF файлу:** `22,469,002` байт (збігається з розміром, вказаним у його внутрішньому header'і).
   - **SHA256 хеш витягнутого файлу:** `182101aff20f774f08833bfbc0f54754f232d8d525e2f0f46d1f102598c40bbb`.
   - **Валідність:** Файл є 100% валідним SWF.

2. **Підготовлена структура для декомпіляції**
   - `extracted/export_instructions.md` — містить інструкції щодо подальшої роботи з FFDec.
   - Створені папки: `extracted/export/scripts/`, `extracted/export/image/`, `extracted/export/sound/`, `extracted/export/text/`.

## Що вже відомо
- Файл успішно виділено з exe-обгортки. Він не містить додаткової обфускації, що приховує сам SWF.
- SWF є некомпресованим (сигнатура FWS), тому з ним легко працюватимуть стандартні декомпілятори.

## Що ще невідомо
- Як саме організована логіка гри (ActionScript 2 чи ActionScript 3). Зважаючи на версію 14, це швидше за все AS3, але вимагає підтвердження після декомпіляції.
- Чи використовується якась внутрішня обфускація коду (наприклад, DoABC обфускація, шифрування ресурсів).
- Скільки загалом ассетів всередині та їхні формати.

## Наступний найкращий крок
- Виконати експорт артефактів (`script`, `image`, `sound`, `text`) за допомогою JPEXS Free Flash Decompiler (CLI: `java -jar ffdec.jar -export script,image,sound,text "extracted/export" "extracted/game.swf"`) на машині, де встановлено цей інструмент, або додати його в поточне середовище.
- Після експорту здійснити первинний огляд вихідного коду ActionScript.
